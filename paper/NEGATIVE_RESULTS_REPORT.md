# Glaubenskrieg 负结果完整报告

> **日期**: 2026-06-06 | **范围**: 3 市场 × 6 范式 × 477 美股 × 10 年 × GARCH 基准
> **核心结论**: OHLCV 日频衍生特征在任何市场上均不包含可检测的日频收益预测信号

---

## 一、跨市场 IC 穷举 — 零信号是全局结论

### 统一对比表

| 维度 | A 股 (multi-asset) | A 股 (cross-sectional) | 美股 |
|------|:----:|:----:|:----:|
| 股票数 | 200 | 200 | **477** |
| 数据跨度 | ~3 年 | ~2.4 年 | **~11 年** |
| Walk-forward 窗口 | 3 | 6 | **10** |
| | | | |
| **LGB IC** | +0.053 ± 0.054 | −0.003 ± 0.042 | **+0.007 ± 0.043** |
| **Ridge IC** | +0.006 | +0.030 ± 0.054 | **+0.031 ± 0.030** |
| **IC > 0.02?** | ❌ | ❌ | **❌** |
| | | | |
| LGB Sharpe | +0.19 ± 0.88 | +0.75 ± 1.10 | +1.16 ± 0.86 |
| Ridge Sharpe | — | +0.48 ± 0.50 | +0.82 ± 0.39 |

**关键负结果 #1**：没有任何市场、任何模型、任何窗口数能产生 > 0.02 的 IC。即使将数据量扩大 3.6 倍（477 美股 × 10 年），IC 仍为 0.007 — 与零无统计差异。

**关键负结果 #2**：451 参数的 Linear Ridge 与 97,000 参数的 Mamba SSM 预测能力完全相同（IC 均为 ≈0.006）。DL 的 96,549 个额外参数仅引入过拟合噪声。

## 二、六种范式全部失败

### 范式穷举裁决表

| # | 范式 | 方法 | 实验规模 | 关键指标 | 裁决 |
|:--:|------|------|:------:|----------|:----:|
| **1** | Deep Learning | CTM (Mamba SSM) v1→v5 | 5 种子 × 5 迭代 | Test IC ≈ 0.00, Test Sharpe = −0.028 | ❌ |
| **2** | Gradient Boosting | GBDT (Hoffnung C++) | 9 窗口 × 5 种子 | Val IC = 0.008, Val Sharpe = −0.088 | ❌ |
| **3** | Hybrid Ensemble | Ensemble + TimeGate (TGPE 三变体) | 3 变体 × 3 种子 | Val IC = 0.028−0.065, Test Sharpe 全负 | ❌ |
| **4** | Feature Engineering | LightGBM + EMA + DM 检验 | 2 EMA × 5 种子 | Test IC = −0.004, DM 4/5 显著但 IC=0 | ❌ |
| **5** | Cross-Sectional Ranking | lambdarank + CS z-scores | 3 种子 | Test Rank IC 负值 | ❌ |
| **6** | Meta-Labeling | XGBoost binary filter | 5 种子 | Δ Sharpe = −0.13 (WF), −0.22 (HO) | ❌ |

### 各范式详细失败记录

#### 范式 1: Deep Learning (CTM Mamba SSM)

```
v1→v5 演变:
  v3: val_IC = 0.14, test_IC = ??   ← 过拟合假象
  v5: val_IC = 0.049, test_IC = 0.006 ← 5 个 bug 修复后
  真实 test_IC = 0.006               ← 与 Ridge 451 参数完全相同
  
  97,000 参数 Mamba SSM = 451 参数 Linear Ridge
  结论: DL 复杂度添加噪声，不添加信号
```

#### 范式 2: Gradient Boosting (GBDT)

```
GBDT v5: Val IC = 0.008, Val Sharpe = −0.088
GBDT 参数扫描: 100/200/500 trees × depth 4/6/8 → 全部相同结果
GBDT 是"诚实的测谎仪"——不会产生虚假的乐观 IC
```

#### 范式 3: Hybrid Ensemble (TGPE)

```
TimeDecayGate:  α,β,γ 训练 10 epoch 仅移动 <0.6% — 门控未学习
Curriculum:     污染 test-prep 训练，模型学到依赖 GBDT 而非 CTM
TimeGate IC:    0.028 − 0.065 (均低于 CTM-only 的 0.049)
结论: 融合零信号模型仍然是零信号
```

#### 范式 4: Feature Engineering (LightGBM + EMA)

```
原始特征 (EMA=1):  Test IC = −0.004, DM 4/5 显著
平滑特征 (EMA=10): Test IC = −0.013, DM 0/3 显著
EMA 平滑反而降低预测质量 → 唯一的微弱信号也被抹除
```

#### 范式 5: Cross-Sectional Ranking (lambdarank)

```
全部 3 种子 Test Rank IC 为负值 (−0.019 到 −0.031)
横截面排名比时间序列更差 → 模型学到的排序与实际未来收益负相关
```

#### 范式 6: Meta-Labeling

```
Walk-forward Δ Sharpe: −0.13 (平均)
Hold-out Δ Sharpe:    −0.22 (平均)
Meta Precision ≈ 0.50 (等于随机)
前提不满足: 主模型 IC ≈ 0 → 元模型无信号可过滤
```

## 三、GARCH(1,1) 完胜 LightGBM — ML 在波动率预测中也是噪声

### 47 只美股 walk-forward 对比

| 预测器 | 平均 QLIKE | 中位数 QLIKE | 获胜次数 |
|--------|:---------:|:----------:|:------:|
| **GARCH(1,1)** | **2.31** | **2.16** | **47/47 (100%)** |
| 历史均值 | 2.43 | 2.26 | 0/47 |
| LightGBM | 12.75 | 5.75 | 0/47 (0%) |
| 持续性 | 436.90 | 291.83 | 0/47 |

**统计检验**：
- Diebold-Mariano (LGB vs GARCH): DM = −6.73, **p = 1.6 × 10⁻¹¹**
- LightGBM 劣于 GARCH 的 p 值 = 万亿分之一

**致命发现**: GARCH 仅需 3 个参数 (ω, α, β)，LightGBM 用了 200 棵树 + 10 个特征。更复杂的模型不仅没有提供更好的预测，而且**显著更差**。这是过拟合在波动率领域的直接证据。

|------|:------:|:--------------:|
| 等权 (基准) | 1.080 | — |

**LGB 波动率预测在截面上无任何价值** — 用其做逆波动率加权不仅没有提升 Sharpe，反而比简单的等权配置更差。这说明 LGB 对"哪些股票波动率更高"的排序能力不超过随机。

## 六、Sharpe 悖论 — 正 Sharpe ≠ 预测能力

### 关键证据

```
FE LightGBM:  Test IC = −0.004  →  Test Sharpe = +0.62
Linear Ridge: Test IC = +0.006  →  Test Sharpe = +0.55
US LGB-MSE:   Test IC = +0.007  →  Test Sharpe = +1.16
```

**解释**: sign-based 长/短策略（做多预测收益最高的 20%，做空最低的 20%）在零 IC 下仍产生正 Sharpe。这是组合构造方式的统计特性（波动率收割 + 均值回复），不是 alpha。

## 七、架构演进全记录 — 每次修复都降低 IC

```
v1: val_IC ≈ 0.08-0.12   (原始 Mamba, state_dim=16, n_layers=3)
v2: val_IC ≈ 0.06-0.10   (多资产 cross-attention, 发现 shuffle bug)
v3: val_IC = 0.14        (修复评估, 但窗口重叠 96%)
v4: val_IC = 0.028-0.065 (TGPE 三变体, 全劣于 v3)
v5: val_IC = 0.049       (5 个 bug 修复, state_dim→8, n_layers→2)
    test_IC = 0.006      ← 真实泛化能力 = 零
```

**每次"改进"都让 IC 更诚实，最终收敛到真实值 0。** v3 的 0.14 是完全的过拟合假象。

## 八、5 步 IC 悖论诊断 — 验证 v5 的 IC 是过拟合

| 步骤 | 诊断 | 发现 |
|:----:|------|------|
| 1 | Checkpoint → held-out test IC | test_IC = 0.006 (仅为 val_IC 0.049 的 12%) |
| 2 | 线性基线对比 | Ridge 451 参数 = CTM 97K 参数 (IC 同为 0.006) |
| 3 | 逐窗口 IC 稳定性 | w0=0.019, w1=0.074, w2=0.041 (方差极大) |
| 4 | Per-stock IC | 均值 0.016±0.069, 60% 正 (二项检验 p=0.10) |
| 5 | Loss gap | Train loss 持续下降, Val loss 在 epoch 10 反弹 |

**所有 5 步均不通过 → IC 是过拟合噪声，非真实信号。**

## 九、根本原因 — 不可修复

1. **OHLCV 衍生特征 = 价格数据的确定性函数** → 无外部信息源
2. **日频颗粒度太低** → 大部分 alpha 在日内微观结构衰减
3. **金融计量学硬上限** → 日频收益 OOS-R² ≤ 1%, IC ≤ 0.02
4. **任何特征工程的组合都无法从价格数据中创造新信息**
