## 二、MambaStock — 代码存在但结论无效

### 仓库信息

```
GitHub: github.com/zshicode/MambaStock
Stars: ~50
Files: main.py (124行) + mamba.py (365行) + pscan.py (225行)
Data: 4 CSV (中国银行股, TuShare 下载)
```

### 实测运行结果

```bash
$ python main.py --epochs 5 --n-test 100 --ts-code 601988

Training: 2007-01-04 → 2021-10-20 (3582 天)
Testing:  2021-10-21 → 2022-03-17 (100 天)
结果: MSE=0.0103, R²=-4.70
```

**R² = −4.70 说明模型比预测均值还要差 5.7 倍。** 对于具有 0.99 自相关的银行股价格，"预测昨日收盘价"就能达到 R² ≈ 0.99。Mamba 模型的真实表现是灾难性的。

### 致命缺陷清单

| # | 缺陷 | 严重度 | 详情 |
|:--:|------|:----:|------|
| 1 | **预测价格而非收益** | 🔴 致命 | 股价自相关 ~0.99，"预测昨日收盘价" R² ≈ 0.99。任何声称的预测能力都是自相关假象 |
| 2 | **仅 4 只股票** | 🔴 致命 | 全部为中国国有银行股 (600036, 601288, 601328, 601988)。同行业、同市值、同波动特征 |
| 3 | **无 walk-forward** | 🔴 致命 | 简单 train/test split (最后 300 天为 test)。单个时间点划分，无法评估跨时期稳定性 |
| 4 | **无线性基线** | 🔴 致命 | 没有 Ridge/OLS 对比。无法判断 Mamba 是否优于简单模型 |
| 5 | **无统计检验** | 🟡 严重 | 无 DM 检验、无排列检验、无置信区间 |
| 6 | **预测目标错位** | 🔴 致命 | 论文声称预测股价，但实际可交易的是收益率。价格序列的非平稳性使 MSE/R² 无意义 |
| 7 | **超小模型** | 🟡 | hidden=16, layer=2 → 参数极少，但这不是问题（小模型不是缺陷，缺乏基线才是） |

### 与 Glaubenskrieg 协议对比

| 协议要素 | MambaStock | Glaubenskrieg |
|------|:---:|:---:|
| 预测目标 | **价格** (自相关 ~0.99) | **5 日收益** (自相关 ~0.00) |
| 股票数 | **4** (同行业) | 200-477 (跨行业) |
| 时间跨度 | 15 年 | 3-11 年 |
| Walk-forward | ❌ 单次 split | ✅ Purged WF (11 窗口) |
| 线性基线 | ❌ | ✅ Ridge 451 参数 |
| IC 计算 | ❌ | ✅ Spearman Rank IC |
| DM 检验 | ❌ | ✅ |
| 多市场 | ❌ | ✅ HK + A + US |
| 可复现性 | ⚠️ 代码可运行但结论无意义 | ✅ 完整代码+结果+数据 |

### 复现裁决

**技术上可以运行代码，但结论无任何科学价值。** 复现它只会证明你可以在高自相关序列上过拟合一个 R² 近 1.0 的模型——这是计量经济学 101 的常识。将其作为基准对比反而会降低 Glaubenskrieg 论文的可信度。

1. **MambaStock**: 代码可运行但结论基于预测价格（非收益），无科学价值。复现它只会浪费时间。
2. **SAMBA**: 无代码。从零重建 GNN+Mamba 架构需数周，且缺少关键的图数据定义。

### 可考虑复现

3. **CNN-LightGBM (Bai et al.)**: 
   - 方法论最可信 (Tier 1 ★★★★☆)
   - 与 Glaubenskrieg 管线兼容
   - 去噪组件已有基础
   - **但**: 关键前提是去噪必须有效。Glaubenskrieg 的 EMA 经验（反而降低 IC）警示：滤波器不创造信号。

### 更高效的替代方案

与其花 1-2 周复现 CNN-LightGBM，不如：
1. 直接实现**去噪对比实验** (小波 vs EMA vs 原始) — 1-2 天
2. 如果去噪在 Glaubenskrieg 数据上有效 → 再考虑完整 CNN-LGB 复现
3. 如果去噪无效 (如 EMA) → 避免 7-11 天的沉没成本

**建议**: 先用 1 天实现正确的因果小波去噪并在 US 数据上测试。如果 ΔIC > 0.01，再投入完整复现。否则，将 "去噪无效" 作为负结果写入论文。
