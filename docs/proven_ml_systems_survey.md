# 现存被证实可用的 ML 投资系统 — 调查报告

> **日期**: 2026-06-06 | **范围**: 学术界 + 工业界 + 已知量化基金
> **目的**: 对比 Glaubenskrieg，识别差距与改进方向

---

## 一、证据等级定义

| 等级 | 标准 | 示例 |
|:----:|------|------|
| ★★★★★ | 大规模 OOS 验证 + 独立复现 + 成本调整 + 统计检验 | McElfresh 表格数据基准 |
| ★★★★☆ | 多市场 OOS + 统计检验，但未独立复现 | VLSTM 牛津基准, Glaubenskrieg |
| ★★★☆☆ | 单一数据集 OOS，方法新颖但待验证 | SAMBA, DASF-Net |
| ★★☆☆☆ | 有前途的想法，验证不完整 | PULSE-KAN, Kronos |
| ★☆☆☆☆ | 声称被反驳或存在严重方法论缺陷 | MambaStock, FinCon |

## 二、分层系统目录

### Tier 1: 最高证据等级（★★★★★ ~ ★★★★☆）

#### 1.1 CatBoost / LightGBM — 表格数据之王

| 维度 | 详情 |
|------|------|
| **方法** | 梯度提升决策树 (GBDT)，函数空间梯度下降 + 随机子采样 |
| **证据** | McElfresh et al. (NeurIPS 2023): 176 数据集 × 19 算法 × 538K 模型 |
| **结论** | CatBoost 综合最优；GBDT 在不规则/大数据集上全面优于 DL |
| **关键机制** | 轴对齐分裂天然处理异方差/缺失值/不规则分布 |
| **Glaubenskrieg 对比** | ✅ 已使用 LightGBM → 与文献结论一致 (IC=0 是信号问题非模型问题) |

#### 1.2 Linear Ridge / OLS — 最强基线

| 维度 | 详情 |
|------|------|
| **方法** | L2 正则化线性回归 |
| **证据** | Gu, Kelly & Xiu (2020): 个股月度 R² ≈ 0.4%；Kang (2026): 简约线性模型 Sharpe 1.30 vs LSTM 0.07 |
| **Glaubenskrieg 对比** | ✅ Ridge test IC = 0.031 (US), 0.006 (HK) — 与 DL 持平，验证"不需要复杂度" |

#### 1.3 VLSTM (牛津基准, 2026) — 最高 Sharpe 的 DL 系统

| 维度 | 详情 |
|------|------|
| **方法** | VSN (变量选择网络) + LSTM，直接优化负 Sharpe |
| **数据** | 15 年期货数据 (5 资产类别), 50 种子 × 选前 10 |
| **结果** | Gross Sharpe 2.39 (未扣除成本), 最低换手模型仅 0.35 |
| **关键设计** | VSN 自适应特征门控 + 池化组合收益优化 + HAC-adjusted 显著性 |
| **Glaubenskrieg 差距** | ❌ 无特征选择网络; ❌ 无组合级优化; ❌ 无期货/多资产类别数据 |

#### 1.4 CNN-LightGBM (Bai et al., Symmetry 2026) — 最可信的混合架构

| 维度 | 详情 |
|------|------|
| **方法** | CNN 去噪 → LightGBM 预测; 逐窗口标准化 + 单向去噪 |
| **数据** | NIFTY50, OHLCV |
| **结果** | OOS-R² = 0.0285 (p<0.01), DM t=-2.51 vs 独立 LGB |
| **消融关键发现** | 去噪贡献 **93%** 的增益; 编码器贡献次要 |
| **Glaubenskrieg 差距** | ❌ 无法获取去噪增益 (已尝试 EMA 平滑 → 反而降低 IC); ❌ 无 DM 检验集成 |

#### 1.5 日内股票可预测性 (SSRN 4496917)

| 维度 | 详情 |
|------|------|
| **方法** | 9 亿观察值, 线性和非线性模型 |
| **发现** | 线性模型统计上最强; 非线性模型经济上更优 |
| **Glaubenskrieg 差距** | ❌ 仅日频数据; ❌ 无订单簿/微观结构数据 |

### Tier 2: 有希望但未充分验证（★★★☆☆）

#### 2.1 SAMBA — GNN + Mamba 股票图

| 维度 | 详情 |
|------|------|
| **方法** | 双向 Mamba + 自适应图卷积 (AGC) |
| **结果** | IC 提升: NASDAQ 85%, NYSE 36%, DJIA 33% |
| **局限** | 仅 3 个指数; 未报告扣除成本后收益; 图结构定义任意 |
| **Glaubenskrieg 差距** | ❌ 无 GNN 组件; ❌ 无股票关系图建模 |

#### 2.2 DASF-Net — 多模态 GNN + FinBERT

| 维度 | 详情 |
|------|------|
| **方法** | 双图扩散 (行业+基本面) + FinBERT 情绪 + LSTM |
| **结果** | MSE 降低 91.6% vs MGAR 基线 |
| **局限** | 仅 12 只股票, 2020-2023; 样本外期间与训练期高度重叠 |
| **Glaubenskrieg 差距** | ❌ 无文本/情绪数据; ❌ 无行业图; ❌ 无多模态融合 |

#### 2.3 多模态波动率网络 (M2VN)

| 维度 | 详情 |
|------|------|
| **方法** | 时序特征 + 非结构化新闻 → 波动率预测 |
| **Glaubenskrieg 对比** | ✅ 已实现波动率预测 (QLIKE=-7.10); ❌ 无文本增强 |

## 四、Glaubenskrieg vs 顶尖系统的十大差距

| # | 差距维度 | Glaubenskrieg | 顶尖系统 | 严重度 |
|:--:|------|------|------|:----:|
| 1 | **数据源** | 9 个 OHLCV 衍生特征 | 多模态: 基本面+文本+另类+订单簿 | 🔴 致命 |
| 2 | **频率** | 日频 | 日内/分钟级/逐笔 | 🔴 致命 |
| 3 | **资产池** | 200~477 只股票 | 数千只 + 多资产类别 (期货/外汇/期权) | 🟡 |
| 4 | **特征选择** | 固定 9 个特征 | VSN 自适应门控 / 数百万 alpha 挖掘 | 🟡 |
| 5 | **去噪** | EMA (反而降低 IC) | 逐窗口标准化 + 单向去噪 (贡献 93% 增益) | 🔴 |
| 6 | **优化目标** | Per-stock MSE/Sharpe | 组合级 Sharpe 直接优化 | 🟡 |
| 7 | **股票关系** | Cross-Attention (O(N²), 无结构) | GNN + 行业图 + 供应链图 | 🟡 |
| 8 | **元学习** | Meta-Labeling (失败) | 三重屏障 + 动态仓位管理 | 🟡 |
| 9 | **验证协议** | Walk-forward + test set | Purged CV + DM test + Deflated Sharpe + 排列检验 | 🟢 |
| 10 | **执行模型** | 无 | 市场微观结构感知 + 冲击成本模型 + 暗池路由 | 🟡 |

## 五、最可行的改进路径

### 路径 A: 去噪优先 (参考 Bai 2026, 最快见效)

```
当前: OHLCV → compute_all_features → LightGBM → IC≈0
改进: OHLCV → 逐窗口标准化 → 单向小波去噪 → LightGBM

关键: 去噪在 NIFTY50 上贡献了 93% 的 OOS-R² 增益
时间: 2-3 天 | 风险: 中等 (EMA 在 Glaubenskrieg 上无效)
```

### 路径 B: 日内数据 (参考 SSRN 4496917, 最高 SNR)

```
当前: 日频 OHLCV
改进: 5秒/1分钟 K线 → 订单簿特征 (价差, 深度, OFI) → LightGBM/Ridge

关键: 日内可预测性"无处不在" (9亿观察值证实)
时间: 2-4 周 (需 IBKR 账户) | 风险: 中低
```

### 路径 C: 多模态融合 (参考 DASF-Net, 最根本)

```
当前: 仅价格特征
改进: OHLCV + FinBERT 情绪 + SEC 基本面 + FRED 宏观 → 多模态融合

关键: DASF-Net MSE 降低 91.6%; 需要外部信息源
时间: 4-8 周 | 风险: 中高 (文本数据获取 + NLP 管线)
```

### 路径 D: 组合级优化 (参考 VLSTM, 方法论提升)

```
当前: Per-stock MSE 最小化 → 选股
改进: 直接优化组合 Sharpe (可微排序 + 池化)

关键: VLSTM 通过组合级优化达到 Sharpe 2.39
时间: 1-2 周 | 风险: 中 (已有 DL 框架, 改损失函数即可)
```

### 路径 E: 波动率策略深化 (已验证可行)

```
当前: 逆波动率加权 (Sharpe Δ = +0.001~0.056)
改进: 波动率曲面 → 期权跨式/宽跨式 → 波动率风险溢价收割

关键: 波动率预测是三市场唯一稳健范式
时间: 2-4 周 | 风险: 低 (但需期权数据)
```

|:------:|------|------|

## 七、核心结论

> **Glaubenskrieg 的 IC=0 不是方法论失败，而是信号瓶颈的诚实反映。** 所有被证实可用的 ML 投资系统（Renaissance, Two Sigma, AQR, VLSTM, CNN-LGB）的共同特征不是更好的模型架构，而是**更丰富的信息源**（另类数据、文本、订单簿）和**更短的预测周期**（日内而非日频）。
>
> Glaubenskrieg 的严格验证协议（walk-forward + held-out test + 线性基线 + 跨市场对比）本身是顶尖水平的——问题在于输入信号的质量上限，而非方法的有效性。
>
> **最优路径**: 在已验证的波动率预测基础上深化 → 同时获取日内/另类数据 → 最终实现多模态+高频的完整系统。
