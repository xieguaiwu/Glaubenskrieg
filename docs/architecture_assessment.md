## 3. 过拟合根因分析

### 3.1 🔴 根因 1: 最终测试评估架构损坏

**文件**: `scripts/train.py` L778-846

```
WALK-FORWARD 模型        最终测试模型
      ↓                      ↓
  验证 Sharpe             测试 Sharpe
  (+2.04)                 (-0.56)
      ↓                      ↓
  同一个实验              但来自完全不同的训练!
```

测试模型是一个**全新随机初始化的模型**,在 train+val 合并数据上训练,与 walk-forward 模型**无任何关系**。

四个致命缺陷:

| # | 缺陷 | 影响 |
|:---:|:---|:---|
| 1 | `shuffle=True` 破坏时序因果 | 相邻序列 62/63 重叠, 打乱后模型可"记忆"而非"预测" |
| 2 | 无验证、无早停 | 固定 50 epoch, 保证过拟合 |
| 3 | Per-batch Sharpe 损失在打乱后更恶劣 | 噪声被放大 |
| 4 | Train+val 合并泄露中间期模式 | 模型学到的 val 期模式在 test 期可能反转 |

**结论**: CTM 的 val_sharpe=+2.04 与 test_sharpe=-0.56 之间**不存在直接关系** - 它们来自两个独立的训练过程。此测试设计使 walk-forward 验证完全失去意义。

### 3.2 🔴 根因 2: Sharpe 损失鼓励退化解

**文件**: `src/model/losses.py` L33-54, `src/utils/metrics.py` L27-56

三条退化路径:

```
Sharpe = μ(策略收益) / σ(策略收益)

路径 1 - 方差坍缩:
  模型输出 → 0 → tanh(pred) ≈ 0 → σ(策略) → 0 → Sharpe → ∞
  (代码已通过 pred_std 监控检测到,但从未干预)

路径 2 - Per-batch 噪声:
  T=63 时间步的 Sharpe 标准误 ≈ 1/√63 ≈ 0.126
  优化器追逐 batch 噪声峰值,而非真实信号

路径 3 - 非可加性:
  mean_{batch}(Sharpe) ≠ Sharpe(concat_all_batches)
  跨 batch 聚合掩盖真实信号
```

### 3.3 🔴 根因 3: 早停对噪声过度敏感

**文件**: `src/train/advanced_trainer.py` L213-225

| 问题 | 说明 |
|:---|:---|
| 监控噪声 Sharpe | `val_window=200` 序列的 Sharpe 标准误 ~0.07,不足以可靠选择模型 |
| patience=10 太宽松 | 100 epoch 中,Sharpe 随机波动即可在 epoch 30 命中峰值,然后永远不触发早停 |
| 无平滑 | `best_state` 在单次噪声峰值冻结,无 top-K 集成或 EMA 平滑 |

### 3.4 🟡 根因 4: Walk-forward 窗口 90% 重叠

`step_size=21`,`val_window=200`:相邻验证窗口重叠 `200-21=179` / 200 = **89.5%**。

报告的 `std_sharpe` 在高度依赖的样本上计算,夸大了结果稳定性的表象。有效独立窗口数仅为 ~10 个而非 28-37 个。

### 3.5 🟡 根因 5: LR 预热从未完成

`lr_warmup_epochs=200` > `n_epochs=100`:模型在整个训练过程中学习率单调递增,从未进入衰减阶段。模型在末期以最大 LR 训练,此时最易过拟合。

## 4. 架构深度分析

### 4.1 MultiAssetCTM 架构图

```
Input: (B, N=50, T=63, D=9)
    │
    ├── Asset Embedding (N→64) ── 3,200 params (2.0%)
    │
    ├── Shared Mamba Backbone ×3 ── 93,056 params (59.2%)
    │   ├── InputProj(9→64) + CausalConv1d(k=3)
    │   ├── MambaBlock ×3: SSM(d_state=16, d_model=64)
    │   │   └── Per-block: W_in 16.4K + Conv 0.4K + SSM 5.6K
    │   └── Dead heads: output_dim=64 但被外层覆盖 ── 4,355 dead params
    │
    ├── Cross-Asset Attention ── 52,292 params (33.2%)
    │   ├── Q/K/V/Out Linear(64→64): 4×4,160 = 16,640
    │   ├── adj_bias: N×N = 2,500 (each seed learns independent graph)
    │   ├── FFN: 64→256→64 = 33,088 (GELU + Dropout)
    │   └── Per-time-step independent attention over N assets
    │
    └── Output Heads ── 260 params (0.2%)
        ├── head_regression: Linear(64→1) = 65
        └── head_classification: Linear(64→3) = 195

TOTAL: 157,323 params | Train samples: 777 | Ratio: 202:1
```

### 4.2 跨资产注意力: O(N2) 的过拟合风险

```
时间步 t 独立执行:
  For each asset i:
    attn[i,j] = softmax(q_i · k_j / √64 + adj_bias[i,j])  ∀j
    out[i] = Σ_j attn[i,j] · v_j

adj_bias: nn.Parameter(zeros(N, N)) - 全连接可学习图
  N=50 → 2,500 可学习边
  N=200 → 40,000 可学习边
```

**核心问题**: 2,500 对资产关系 vs 777 训练样本 = **每样本 3.2 对关系**。模型必然学到噪声相关性。FFN (64→256→64, 33K params) 进一步放大这些虚假模式。

### 4.3 Mamba SSM: 适合金融时序吗?

| 优势 | 劣势 |
|:---|:---|
| 因果性构造保证无前瞻偏差 | T=63 过度工程化 (Mamba 为 100K+ tokens 设计) |
| 状态空间可表示潜在市场体制 | d_state=16 × 128 通道 = 2,048 状态元素 - 过大 |
| 选择性门控类似 GRU/LSTM | Ascend 910B 兼容层: 每步 0.5-1s vs 正常 0.01-0.05s |
| O(T) 线性复杂度 | 对 T=63 简单 GRU (~50K params) 可替代 |

### 4.4 死参数

backbone 的 `output_dim=64` 创建了未被使用的 `head_regression(64→64)` 和 `head_classification(64→3)` - **4,355 params (2.8%) 白白浪费**。设置 `output_dim=0` 即可消除。

### 5.3 为什么没有完全崩溃?

尽管严重过度参数化,模型未完全崩溃的原因:

1. **跨资产参数共享**: backbone 在 50 个资产上共享权重 → 每个梯度 batch 实际含 50× 信息
2. **跨时间参数共享**: SSM 矩阵在所有 63 时间步复用 → 有效参数更少
3. **激进正则化**: dropout=0.2, weight_decay=0.15, L2 λ=0.01
4. **Walk-forward 验证**: 多窗口提供诚实的样本外评估

**但 GBDT IC≈0.02 揭示了底层真相**: 信号极弱时,任何过剩容量都会过拟合噪声。

## 7. 架构潜力评分

| 维度 | 评分 | 说明 |
|:---|:---:|:---|
| **数据流正确性** | 9/10 | 特征因果性/目标对齐/划分隔离全部正确,仅类权重有小泄露 |
| **方法论严谨性** | 4/10 | 测试评估设计损坏 + Sharpe 损失退化解 + LR 预热错误 |
| **参数效率** | 3/10 | 202 params/sample, 4-8× 过度参数化, 死代码 4.4K |

| **可复现性** | 8/10 | seed 固定 (已修复), walk-forward 提供诚实验证 |
| **硬件效率** | 3/10 | Ascend 910B 兼容层每步 0.5-1s, ~50× 慢于原生 CUDA |
| **真实预测能力** | **2/10** | GBDT IC≈0.02, dir_acc≈48% - 信号极弱 |

### 7.1 综合评分: **35/70 (5.0/10)**

### 7.2 最终判断

> **架构设计合理但严重过度参数化。方法论存在多处可修复缺陷。即使全部修复,由于股价本身的低可预测性(GBDT IC≈0.02),模型最多达到 marginal 正 Sharpe。**
>
> **论文应诚实地将"无预测能力"作为核心发现**,附带完整的过拟合分析和方法论改进作为贡献。这比强行报告虚假的正 Sharpe 更有学术价值。

# 附录 G: IC 悖论完整诊断

## G.1 悖论陈述

> **CTM v5 的 walk-forward validation 显示 IC = 0.049 (Spearman rank correlation)，但 test Sharpe 始终为负。IC 是真实预测信号还是过拟合假象？**

这是一个典型的金融 ML 悖论：validation 指标显示模型有技能，但样本外表现反而更差。

## G.2 五步诊断流程

### 诊断 1: Checkpoint 直接计算 Held-out Test IC

**方法**: 加载 walk-forward 训练好的 checkpoint，直接在从未见过的 held-out test 集上计算 Spearman rank IC。

| 种子 | Walk-Forward IC | Test IC (checkpoint) | Δ (WF - Test) | 过拟合比例 |
|:----:|:--------------:|:--------------------:|:-------------:|:---------:|
| 42 | 0.044 | 0.006 | +0.038 | 86% |
| 456 | 0.050 | 0.007 | +0.043 | 86% |

**发现**: Test IC ≈ 0.006，仅为 val_IC 的 14%。86% 的 val_IC 未能泛化。

### 诊断 2: 线性基线对比

**方法**: 用最简单的线性 Ridge 回归 (451 params) 在相同数据上运行相同协议。

| 模型 | 参数量 | Test IC | Test Sharpe | 
|------|:------:|:-------:|:----------:|
| CTM (Mamba SSM) | 97,000 | 0.006 | -0.093 |
| Linear Ridge | 451 | 0.006 | **+0.55** |

**发现**: 
- 两种模型的 Test IC 相同 (0.006) — DL 的 96,549 个额外参数未提取任何增量信号
- Ridge 的 Test Sharpe 为 +0.55 — 这是 sign-based 策略构造的伪影，不是预测能力的证据
- **如果 DL 不能显著优于线性模型，不应部署 DL**

### 诊断 3: 逐窗口 IC 稳定性分析

**方法**: 拆解 walk-forward 3 个窗口的 IC，检查一致性。

| 种子 | Window 0 | Window 1 | Window 2 | 均值 | 标准差 | 变异系数 |
|:----:|:--------:|:--------:|:--------:|:----:|:-----:|:-------:|
| 42 | 0.007 | 0.072 | 0.058 | 0.045 | 0.028 | 0.62 |
| 123 | 0.021 | 0.068 | 0.059 | 0.049 | 0.020 | 0.41 |
| 456 | 0.020 | 0.075 | 0.054 | 0.050 | 0.023 | 0.46 |
| 789 | 0.018 | 0.049 | 0.035 | 0.034 | 0.013 | 0.38 |
| 1024 | 0.029 | 0.086 | 0.081 | 0.065 | 0.026 | 0.40 |

**发现**:
- Window 1 的 IC (均值 0.070) 系统性地高于 Window 0 (均值 0.019)，相差 3.7×
- 如果信号真实，所有窗口应有相似的 IC
- 窗口差异可能是数据快照的偶然噪声结构

### 诊断 4: Per-Stock IC 分解

**方法**: 计算每只股票的独立 test IC (50 只股票)，检查信号来源。

```
Per-stock IC 分布:
  均值: 0.016
  标准差: 0.069
  最小值: -0.187
  最大值: +0.215
  正 IC 比例: 60% (30/50)
```

**发现**:
- 60% 的股票 IC 为正 (但弱) — 不显著高于 50% 的零假设
- 少数股票 (5-8 只) 的正 IC 贡献了均值中的大头
- Per-stock IC 的标准差 (0.069) 是均值 (0.016) 的 4.3×
- 用二项检验: P(30/50 正 | H₀: p=0.5) = 0.101 — 不拒绝 H₀

### 诊断 5: Train/Val Loss Gap 分析

**方法**: 检查训练过程中的 train loss vs val loss 分歧。

```
典型训练曲线 (CTM v5 seed 42, window 1):
  Epoch 5:  train_loss=0.87  val_loss=0.93  gap=+0.06  ← 正常
  Epoch 10: train_loss=0.72  val_loss=0.89  gap=+0.17  ← 过拟合开始
  Epoch 15: train_loss=0.58  val_loss=0.92  gap=+0.34  ← 严重
  Epoch 19: train_loss=0.51  val_loss=0.96  gap=+0.45  ← 早停触发
```

**发现**: Train loss 持续下降但 val loss 在 epoch 10 后反弹 — 经典过拟合迹象。早停 (patience=5) 在 epoch 19 触发，但此时已经过度训练。

## G.3 诊断综合结论

| 诊断步骤 | 关键发现 | 信号真实性支持？ |
|:--------:|----------|:---------------:|
| 1. Test IC 直接验证 | val_IC 的 86% 不泛化 | ❌ 不支持 |
| 2. 线性基线 | DL = 线性 (IC 相同) | ❌ 不支持 |
| 3. 窗口稳定性 | Window 1 异常高 (3.7×) | ❌ 不支持 |
| 4. Per-stock IC | 60% 正不显著 (p=0.10) | ❌ 不支持 |
| 5. Loss gap | 经典 U 形过拟合曲线 | ❌ 不支持 |

> **最终判定: Walk-forward IC = 0.049 是过拟合假象。真实 test IC ≈ 0.006，统计上不可区分于零。Glaubenskrieg 数据上不存在可检测的日频收益预测信号。**

## G.4 通用诊断框架

此五步流程可作为**金融 ML 通用验证框架**:

1. ✗ Checkpoint → held-out test IC: 必须接近 val_IC
2. ✗ 线性基线对比: DL 必须显著优于 Ridge
3. ✗ 跨窗口 IC 稳定性: CV < 0.3
4. ✗ Per-stock IC 显著性: 二项检验 p < 0.01
5. ✗ Train/val loss gap: 无 U 形分歧

所有 5 项全部通过才可声称发现预测信号。

| 789 | 0.029 | -0.068 | -0.012 | +0.471 | -1.55 | 0.121 | ❌ |
| 1024 | 0.033 | -0.023 | -0.013 | +0.493 | -1.72 | 0.086 | ❌ |
| **平均** | **0.029** | **-0.067** | **-0.013** | **+0.474** | — | — | 0/5 |

## H.3 关键发现

### 1. EMA 平滑降低预测质量

```
       Test IC     Test Sharpe    DM 显著
EMA=1: -0.004      +0.620         4/5 (80%)
EMA=10: -0.013     +0.474         0/5 (0%)

平滑 → IC 更负, Sharpe 更低, DM 显著性消失
平滑 = 丢弃高频信息 = 唯一可能的弱信号也被抹除
```

### 2. Test IC 恒为零

无论是否平滑，test IC ≈ 0.00。EMA=1 的 mean test IC = -0.004，与零不可区分。正 DM 统计量来自 Sharpe 的差异而非预测质量的差异。

### 3. 正 Sharpe 来自策略构造，非预测能力

```
Test IC = -0.004 (≈ 0) 但 Test Sharpe = +0.62？

解释:
  sign-based 策略: 做多预测收益前 20% 股票，做空后 20%
  → 在波动率充分的市场上
  → 做多前 20% 等价于持有近期最强的股票 (均值回复)
  → 做空后 20% 等价于做空近期最弱的股票 (均值回复)
  → 此组合实际上是一个风格因子 tilt，非 alpha
  → 产生正 Sharpe 但不来自预测能力
```

### 4. Phase 1 决策门: 不通过

Bai et al. 方法论 (CNN 去噪 → LightGBM) 要求 test IC > 0.02 且 DM 检验显著。本实验:
- Test IC = -0.004 (远低于 0.02)
- DM 显著性来自 Sharpe 质量差异而非 IC 差异
- EMA 平滑反而恶化结果

**决策**: 放弃纯价格特征方向。转向多模态数据或不同预测目标。

# 附录 I: 横截面排名 (Cross-Sectional Ranking) 结果

## I.1 实验动机

López de Prado (2018) 明确指出: **量化选股的本质是横截面比较，而非时间序列预测。** 前序实验使用 per-stock z-score 标准化，可能破坏了跨资产的排名信号。

本实验测试 **López de Prado 提案 1**: 横截面 lambdarank 是否比时间序列方法更优。

## I.2 方法

| 维度 | 详情 |
|------|------|
| **特征** | 9 个 OHLCV 衍生特征 → 每日 CS z-scores + 5/21/63 日动量排名 + 等权市场收益 = 13 维 |
| **目标** | 5 日 forward return → 五分位离散化 (0-4) → lambdarank 排序学习 |
| **模型** | LightGBM LGBMRanker (objective=lambdarank, metric=NDCG, num_leaves=31) |
| **评估** | Rank IC = 逐日 cross-sectional Spearman rank correlation between model scores and forward returns |
| **协议** | Walk-forward (train=400d, purge=126d, val=80d, step=63d) |

## I.3 完整结果

| 种子 | Walk-Forward Rank IC | Per-Window 分解 | Test Rank IC | 方向 |
|:----:|:--------------------:|-----------------|:------------:|:----:|
| 42 | -0.018 ± 0.023 | w0=-0.012, w1=-0.021, w2=-0.022 | **-0.025** | 全窗口负 |
| 123 | -0.009 ± 0.018 | w0=-0.005, w1=-0.008, w2=-0.013 | **-0.031** | 全窗口负 |
| 456 | -0.015 ± 0.027 | w0=-0.018, w1=-0.009, w2=-0.020 | **-0.019** | 全窗口负 |
| **平均** | **-0.014** | — | **-0.025** | — |

## I.4 与其他方法的对比

| 方法 | 评估指标 | Test 值 | 方向 |
|------|----------|:-------:|:----:|
| CTM 时间序列 | Spearman IC | +0.006 | 微弱正 |
| LightGBM 时间序列 | Spearman IC | -0.004 | 零 |
| **CS lambdarank** | **Rank IC** | **-0.025** | **显著负** |

## I.5 结论

**横截面排名范式反而产生负 Rank IC** — 在所有 3 个种子、所有 9 个窗口上，Rank IC 均为负值。模型学到的排名与实际未来收益排序呈**负相关**。

分析:
1. OHLCV 衍生特征在横截面上同样无预测信息 — 无论时间序列还是横截面，信号均不存在
2. lambdarank 的列表级损失函数不能从噪声中提取信号
3. 负 Rank IC 暗示模型可能学到了某种均值回复模式 (低排名的股票反弹) — 但如果存在这样的结构，正 Rank IC 更容易学到
4. 负 IC 的不稳定性使其不可用于反向下注策略

> **横截面范式失败的根本原因: 200 只 A 股在日频 OHLCV 特征的横截面上不存在可预测的排序结构。**

# 附录 J: 波动率预测完整结果

## J.1 为什么测试波动率预测

波动率预测是金融计量学中最稳固的可预测结构:

```
收益 ≈ 随机游走 + 微小漂移
  → 一阶矩几乎不可预测
  → 日频 R² 上限 ≈ 1%，IC 上限 ≈ 0.02

波动率 = sqrt(方差)
  方差具有:
  - 强自相关性 (方差聚类, Engle 1982 Nobel)
  - 长记忆性 (Bollerslev 1986, FIGARCH)
  - 杠杆效应 (负收益 → 更高未来波动率)
  → 结构稳固、可跨期验证
```

## J.2 实验设计

| 维度 | 详情 |
|------|------|
| **目标** | `realized_vol_21` — 21 日滚动收益标准差 |
| **特征** | 其他 8 个 OHLCV 衍生特征 (exclude realized_vol_21) + 序列上下文 |
| **模型** | LightGBM LGBMRegressor, 500 estimators, max_depth=5 |
| **协议** | 与收益预测完全相同的 walk-forward (train=400d, purge=126d, val=80d, step=63d) |
| **指标** | MSE, MAE, QLIKE (Patton 2011 — 波动率预测标准损失函数) |

# 附录 K: Meta-Labeling 管线完整结果

## K.1 理论背景

Meta-Labeling (López de Prado, 2018 §3) 的核心思想:

> **解耦方向预测 (主模型) 与仓位/交易决策 (元模型)。**
> 主模型输出 "买/卖" 信号。元模型输出 "是否真的执行此交易" (0/1)。
> 元模型**不发明新赌注**，只过滤主模型的假阳性信号。

数学前提 (López de Prado §3.7):
```
P(元模型正确 | 主模型正确) > P(元模型正确)
```
即元模型必须能识别主模型何时可能犯错。

## K.2 管线架构

```
输入 (13 维横截面特征: 9 OHLCV CS z-scores + 3 momentum ranks + market return)
    │
    ▼
主模型: LightGBM lambdarank (五分位排名) → 前20%做多 / 后20%做空 → 交易信号 (direction ±1)
    │
    ▼
元特征 (8 维): raw_score, cs_zscore, percentile, conviction, market_return, vol_zscore, mom_21_rank, direction
    │
    ▼
元模型: XGBoost binary classifier {0=跳过, 1=执行} → 过滤后交易信号
    │
    ▼
策略 PnL = direction × return × meta_decision
```

## K.3 Walk-Forward 结果 (3 窗口, 5 种子)

| 种子 | Precision | Recall | F1 | 主 Sharpe | Meta Sharpe | Δ Sharpe | 交易减少 |
|:----:|:---------:|:------:|:---:|:---------:|:-----------:|:--------:|:--------:|
| 42 | 0.512 | 0.457 | 0.483 | +0.087 | -0.065 | **-0.152** | 53% |
| 123 | 0.508 | 0.439 | 0.471 | +0.112 | +0.028 | **-0.084** | 48% |
| 456 | 0.515 | 0.465 | 0.489 | +0.095 | -0.027 | **-0.122** | 51% |
| 789 | 0.503 | 0.427 | 0.462 | +0.078 | -0.115 | **-0.193** | 55% |
| 1024 | 0.510 | 0.445 | 0.475 | +0.103 | -0.009 | **-0.112** | 49% |
| **平均** | **0.510** | **0.447** | **0.476** | **+0.095** | **-0.038** | **-0.133** | 51% |

## K.4 Hold-Out Test 结果

| 种子 | Precision | F1 | 主 Sharpe | Meta Sharpe | Δ Sharpe | 结论 |
|:----:|:---------:|:---:|:---------:|:-----------:|:--------:|------|
| 42 | 0.498 | 0.451 | -0.124 | -0.348 | **-0.224** | ❌ |
| 123 | 0.492 | 0.443 | -0.089 | -0.402 | **-0.313** | ❌ |

| **平均** | **0.497** | **0.448** | **-0.114** | **-0.341** | **-0.227** | ❌ |

## K.5 核心发现

### 1. Δ Sharpe 全面为负

Walk-forward Δ = -0.13, Hold-out Δ = -0.22。Meta 过滤**降低**而非提升 Sharpe。在 hold-out 上，主模型已有负 Sharpe (-0.114)，Meta 使情况恶化到 -0.341。

### 2. Meta Precision ≈ 0.50 — 等于随机

- Walk-forward: 0.510 (仅比随机高 1%)
- Hold-out: 0.497 (**低于随机**)
- 元模型学到的区分模式在样本外完全消失

### 3. F1 ≈ 0.45 — 无意义分类

F1 在 0.43-0.49 范围内，与随机二分类器的期望 F1 (0.50) 相当或更低。

### 4. 根因: 垃圾进垃圾出

Meta-Labeling 要求:
1. **主模型有正预期 IC** — 本项目不满足 (主模型 IC ≈ 0.000)
2. **元特征与主模型错误模式相关** — 元特征来自同一套 OHLCV 特征，无增量信息

### 5. 与文献的一致性

Guida & Coqueret (2019) 在美股数据上的 Meta-Labeling 也发现: 元模型的增量价值高度依赖主模型的技能水平。当主模型仅有边际技能时，元模型的价值趋向于零或负。

> **Meta-Labeling 不能从无信号的输入中创造信号。如果主模型 IC = 0，元模型无法增加价值。**

| **iTransformer** | 🟢 潜力 | 跨 variate attention — 天然适用于多资产组合预测 |

### 核心结论

> **架构创新不能拯救零信号特征。** Glaubenskrieg 的 9 个 OHLCV 衍生特征的信息已穷竭。2024-2026 的任何新架构 (Mamba-3, xLSTM, TTT, Titans, Griffin, KAN) 若复用相同特征集，将面临相同的天花板: test IC ≈ 0.00。信号必须来自新数据 (文本, 订单簿) 或新预测目标 (波动率, 相关性)，而非新架构。

# 附录 M: 最终项目评估

## M.1 我们学到了什么

### 1. 信号不存在是真实且可验证的

经过 6 种预测范式、5 次模型迭代、数十个种子实验、两代硬件、超过 50 次完整训练:

> **在 200 只 A 股日频数据的 9 个 OHLCV 衍生特征上，不存在任何可检测的每日收益预测信号。**

这不是失败 — 这是答案。这个否定经过了严格的方法论验证:
- 独立 held-out test set (从未用于训练/早停)
- 线性基线对比 (Ridge 451 params = CTM 97K params)
- 跨种子一致性检查 (5 seeds)
- 统计检验 (DM test, 二项检验, permutation 检验设计)
- 多范式旁证 (时间序列, 横截面, 特征工程, Meta-Labeling)

### 2. Walk-forward IC 是危险的伪信号

v3 的 val_IC = 0.14 给人以预测能力充足的假象。但:
- 5 个 bug 修复后降至 0.049
- Held-out test 证实仍包含 86% 过拟合
- 真实 test IC = 0.006

**教训**: 在小数据上 (750 有效样本)，walk-forward validation 本身会过拟合。必须通过 held-out test set + 线性基线 + 统计检验三道关卡。

### 3. 深度学习在表格金融数据上没有魔法

```
               参数量    Test IC    Test Sharpe
Linear Ridge    451      0.006      +0.55
CTM (Mamba)     97,000   0.006      -0.028

额外的 96,549 个参数 = 零增量预测能力 + 额外过拟合
```

这验证了 McElfresh et al. (NeurIPS 2023) 的发现: 在 176 个表格数据集上，无纯 DL 模型击败调优后的 CatBoost/LightGBM。金融数据也不例外。

### 4. 正 Sharpe ≠ 预测能力

```
FE LightGBM: Test IC = -0.004  →  Test Sharpe = +0.62
Linear Ridge: Test IC = +0.006  →  Test Sharpe = +0.55
```

sign-based 长/短组合在零 IC 下可产生正 Sharpe — 这是策略构造的统计特性 (做多近期强股 + 做空近期弱股 ≈ 暴露于低波动率/均值回复因子)，不是 alpha。

### 5. 波动率预测是唯一稳固的结构

5 个种子的 test QLIKE 标准差仅 0.001 — 跨种子一致的指标是真结构的标志。方差聚类效应 (Engle 1982 Nobel) 在数据中稳固存在。

### 6. Meta-Labeling/Gate/Ensemble 不能创造信号

三个不同方法 (TGPE TimeGate, Meta-Labeling XGBoost, Curriculum Dropout) 都基于相同前提: 存在主模型信号，集成/过滤可增强它。当主模型信号 ≈ 0 时，三者全部失败。

### 7. 特征工程天花板是真实的

9 个 OHLCV 衍生特征 = close/volume 的确定性函数。EMA 平滑, wavelet 去噪, CS z-scores, 动量排名 — 所有变换都是同一信息的不同表示。没有外部信息源的特征工程 = 数据美容。

## M.2 什么本可以不同

### 从项目开始就应做的

| # | 建议 | 如果做了... |
|---|------|-----------|
| 1 | **先跑线性基线** | 在 Day 1 就知道 Ridge IC=0.006 — 提前 2 周终止 DL 实验 |
| 2 | **先做特征信息量评估** | 在 Day 1 就意识到 OHLCV 衍生特征 = 无外部信息 |

## M.4 项目最终评价

### 学术价值: ★★★★☆ (4/5)

负结果在金融 ML 文献中稀缺且宝贵。在 Nature 2025 综述证实大多数 DL 股票预测研究不可复现的背景下:
- 经过严格验证的负结果
- 完整的过拟合诊断 (IC 0.14→0.04→0.006 追溯)
- 系统的多范式对比 (6 种范式全部穷举)
- 可复用的验证框架 (五步 IC 诊断)

这些要素构成了一篇有价值的负面结果论文。

### 工程质量: ★★★☆☆ (3/5)

```
优点:
  ✅ 完整的 walk-forward + purged 协议
  ✅ 30 个结构化的源文件
  ✅ 远程 GPU 训练管线
  ✅ 严格的特征因果性检查

缺点:
  ❌ v1-v3 的 test evaluation bug (shuffle=True)
  ❌ 过参数化 (202 params/sample)
  ❌ Ascend 910B 兼容层 (10× 慢)
  ❌ 死参数和冗余设计
  ❌ 类权重轻微泄露
```

### 方法论严谨性: ★★★★☆ (4/5)

```
数据流正确性:   ★★★★★  (无前瞻偏差, 因果关系正确)
过拟合控制:     ★★★☆☆  (v3 有伪 IC, v5 修复后改善)
评估协议:       ★★★★☆  (held-out test + 线性基线 + DM 检验)
结果可信度:     ★★★★★  (跨种子一致, 多范式旁证)
负结果诚实度:   ★★★★★  (未粉饰, 未选择性报告)
```

### 总体: ★★★★☆ (3.8/5)

Glaubenskrieg 是一个**方法论上严谨的负结果项目**。它诚实地穷举了多种 ML 范式，严谨地验证了信号的不存在性，为后续工作提供了清晰的路线图。其学术价值在于提供了一个可复现的参考案例: 当数据不足时，再多架构创新也无法创造信号。
